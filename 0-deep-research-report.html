持续学习 × 后训练（Continual Learning + Post-Training）研究现状：面向 RSI 的顶会与近期预印本综述

执行摘要

研究时间点：2026 年 10 月 27 日。本文重点覆盖 2024–2026 年 ICLR、ICML、NeurIPS，以及 2025–2026 年来自 MIT、UC Berkeley、Oxford、Google DeepMind、FAIR/Meta、UCLA 等团队的近期 arXiv 工作。需要特别说明：NeurIPS 2026 主会将在 2026 年 12 月举行，作者录用通知已于 9 月 24 日发出，但会议尚未举行；因此本文对 NeurIPS 的“已完成、可稳定比较”部分主要以 2024–2025 正式论文为锚点，并用 2026 arXiv 补足最前沿进展。citeturn21search3turn21search7

最重要的结论是：“持续学习 + 后训练”正在从传统的“防止 catastrophic forgetting”问题，转变成一个更广义的持续能力积累（capability accumulation）+ 何时更新（when to update）+ 用什么信号更新（how to update）的问题。UC Berkeley 2026 的统一比较尤其清楚地表明，不同环境变化需要不同机制：prompt/context 方法可以快速适配但容易覆盖稳定知识，蒸馏方法擅长稳定积累但不善于改写过时事实，而在线 RL 对离散知识变化适应最好、却明显依赖奖励质量。citeturn22search0turn24view0

对于 foundation model post-training，on-policy 与 off-policy 的差异正在成为持续学习的核心变量。MIT 的 ICML 2026 Spotlight Self-Distillation Enables Continual Learning 将 demonstration-conditioned 模型作为自身 teacher，在学生自己的轨迹上进行 reverse-KL 蒸馏，从而把 demonstrations 转换成不需要显式 reward 的 on-policy training signal；其知识注入实验中 SDFT 达到 strict/lenient/OOD accuracy = 89/100/98，而标准 SFT 为 80/95/80。citeturn21search0turn21search1turn23view1

与此同时，直接比较 SFT 与 reinforcement fine-tuning 的近期 CPT 工作发现，连续七个多模态任务后，SFT 的平均准确率为 54.0、forgetting measure 为 −10.4，而 GRPO 达到 60.0、FM 为 −2.3；在 MMMU/MMLU-Pro/POPE 等一般能力上，RFT 也明显比连续 SFT 更能保护原模型能力。这使“奖励驱动更新天然是否比 teacher-forced token imitation 更适合持续后训练”成为非常值得 RSI 深挖的问题。citeturn17view1turn22search3

另一个明显趋势是更新局部化：FAIR/Berkeley 用 sparse memory slots 将 NaturalQuestions 上的遗忘从 full fine-tuning 的 89% F1 drop、LoRA 的 71% 降至 11%；UCLA 的 ACLArena 则发现异质 agent post-training 阶段的参数更新只部分对齐，因此用 shared SDFT backbone + per-stage RL LoRA experts 隔离相互冲突的残差；Continual RL 中的 CKA-RL 也采取 task-specific knowledge vectors + adaptive merging。这三条线实际上都指向同一个设计原则：不要让一个稀疏、局部或任务特定的学习信号重写整个模型。citeturn22search5turn25view0turn25view1

因此，对本文所采用的宽泛 RSI 定义，最有潜力的研究交叉点不是单纯“做一个新的 replay 算法”，而是：signal interpretation / uncertainty → credit assignment → sparse or modular update → consolidation → retention evaluation。这条链同时连接稀疏奖励 RL、在线 RL、agent post-training、representation plasticity、模型编辑和 continual knowledge acquisition。该判断是对下述论文的综合推论，而不是某一篇论文的原话。citeturn20search2turn20search3turn20search0turn22search5turn25view0

研究口径与 RSI 假设

RSI 在本问题中不是一个具有统一学术定义的缩写。按照提问中的要求，本文不把它强行绑定到单一定义，而采用两个互补视角：

RSI-Signal：将 RSI 理解为 Reinforcement Signal Interpretation / Reinforcement Sparse Incentives，重点关注奖励稀疏、延迟、噪声、非平稳以及模型如何把弱 reward / demonstrations / teacher distributions 转换成有效更新；因此直接纳入 continual RL、GRPO/RFT、on-policy distillation、TD-style Bayesian continual learning 等工作。MIT 的 SDFT 明确把 demonstration learning 与 on-policy RL 联系起来，Oxford 的 TD-VCL 则从持续 Bayesian update 推导出与 temporal-difference targets 的数学联系。citeturn20search2turn14search4turn19search0

RSI-Representation：将 RSI 理解得更宽，关注稀疏或不频繁的学习信号如何改变 representation、参数子空间和模型 plasticity；因此纳入 Parseval regularization、UPGD、sparse memory finetuning、Weight Space Consolidation、Momentum KD、SAFE 等。它们虽然不一定直接优化 reinforcement reward，但都在解决 RSI 最终不可避免的核心问题：一次有限的新信号究竟应该修改哪些 representation，以及怎样避免这些更新污染先前知识。citeturn20search0turn19search9turn22search5turn21search2turn14search1turn15view4

这里的“post-training”也采用 foundation-model 社区较宽的工程含义，包括 SFT、continual instruction tuning、RFT/RL、on-policy distillation、knowledge insertion、PEFT/LoRA、model merging，以及 agent 的多阶段能力训练，而不仅限于某一种 RLHF pipeline。ACLArena 明确将 reasoning、search、e-commerce、instruction following 等异质训练阶段视为一个 Agent Continual Learning 问题。citeturn25view0turn17view0

领域地图与时间线

从近三年的工作看，方法可以粗略组织成五条相互汇合的路线：on-policy/distillation、reinforcement fine-tuning、parameter/representation localization、plasticity maintenance、replay/consolidation。2026 年最明显的新变化，是这些路线开始在同一个 foundation-model post-training pipeline 中被直接比较和组合，而不再各自作为独立的 continual-learning 技巧存在。citeturn22search0turn20search2turn25view0

趋势与综合判断

第一，continual post-training 正从“数据重放问题”变成“learning-rule 问题”。过去的默认思路往往是先接受 SFT 会忘记，再用 replay、EWC、adapter 或 model expansion 修补；SDFT 与 RFT-CPT 的结果则提示，更上游的问题可能是 SFT 的 off-policy、teacher-forced gradient 本身就更容易产生大范围参数漂移，而 on-policy training signal 可以天然约束更新到当前 policy 实际访问的状态分布。MIT 的结果显示 SDFT 同时提高新任务表现和 retention；多模态 CPT 的对照也显示 GRPO/RLOO 相对 SFT 有显著更小的 forgetting measure。citeturn20search2turn23view3turn17view1

第二，稳定性—可塑性（stability–plasticity）重新成为核心，而不是一个已经“解决”的经典问题。ICLR 2026 的 Forget Forgetting 显示，当 exemplar memory 达到现实中并不昂贵的水平后，单纯防 forgetting 的边际价值下降，真正限制持续能力积累的是旧权重造成的 plasticity loss；Parseval 与 UPGD 从不同角度给出了类似证据：长期训练会让模型越来越难响应新任务/新 reward，即使旧知识保存得很好。citeturn21search2turn20search0turn19search9

第三，2025–2026 最一致的结构趋势是“shared core + localized residual”。FAIR/Berkeley 的 sparse memory slots、UCLA 的 per-stage RL LoRA experts、CKA-RL 的 task-specific knowledge vectors，以及 SAFE 的 slow/fast PET 都避免让每次更新修改整个 shared representation；这些方法形式不同，却都把 interference 控制变成了“更新支持集（update support）应该多大”的问题。citeturn22search5turn15view0turn25view1turn14search2

第四，蒸馏正在从“保存旧输出”转向“产生训练信号”。Momentum KD 使用持续演化的 EMA teacher；SDFT 用 demonstration-conditioned self-teacher 在 student trajectories 上产生 token-level corrections；ACLArena 的 OPD/MMOPD 则让旧 checkpoint 在新模型自身访问的行为状态上充当 teacher。换言之，distillation 在越来越多工作中承担的是一种低方差、稠密、可持续生成的 pseudo-reward / policy-improvement signal角色，而不仅是传统 logit matching。最后一句是本文基于这些方法机制做出的解释。citeturn14search1turn20search2turn25view0

第五，“事实变化”与“新增事实”不能再使用同一个 continual-learning objective。Berkeley 的 TempWiki 结果很关键：SDFT 对累积稳定知识有效，但在必须推翻旧事实时会因为锚定旧 belief 而破坏 stable facts；GRPO 在这个 benchmark 上反而表现出更好的 change/retention trade-off。这意味着 RSI 系统首先必须解释信号究竟表示“添加知识”“修正知识”“短期异常”还是“真正的 regime shift”，再决定是否更新。citeturn24view0turn22search0

第六，evaluation 正从单一 final accuracy 转向多维长期指标。最新工作同时测 new-task accuracy、forgetting measure、forward transfer、stable-vs-drift F1、general benchmark retention、OOD transfer、训练/VRAM 成本甚至 parameter/trainability statistics；这对 RSI 特别重要，因为一个方法完全可能获得更高当前 reward，却通过 representation collapse 换取短期收益。citeturn17view1turn25view1turn24view0turn20search0turn16view1

RSI 开放问题与研究方向

最值得优先研究的是“signal semantics before optimization”。现有 RL 算法通常默认 reward 给定之后就应被最大化，但持续环境中同一个低 reward 可能意味着模型能力不足、环境已经变化、reward model 失真、探索不足或只是高方差随机事件。Berkeley 的 temporal-drift 实验已经说明 noisy reward 会改变不同更新范式的相对优劣；一个 RSI-specific 系统可以在 optimizer 前增加 latent change detector，显式估计 novelty / reliability / permanence / conflict，再决定是否进入 weight update。citeturn22search0turn24view0

第二个方向是 sparse reinforcement signal → sparse parameter credit。FAIR/Berkeley 已证明 factual update 没有必要触碰所有参数：选择少数 memory slots 可以把 held-out F1 degradation 从 71–89% 级别压到 11%。自然的 RSI 扩展是让 reward attribution 决定应该打开哪些 memory slots、LoRA experts、attention heads 或 MLP subspaces，而不是把一个 episode-level scalar reward 通过整个网络反向传播。这是基于 Sparse Memory、MLE 和 UPGD 的综合研究建议。citeturn22search5turn15view0turn20search1

第三个方向是把 SDFT 与真正的 sparse-reward RL 做成两阶段或混合更新。SDFT 的优势是无需 reward 即可从 demonstration 生成 dense token-level correction，而 ACLArena 的诊断显示 SFT/SDFT 更适合建立宽泛、方向一致的行为，RL 的更新则更小、更 policy-local、适合最终 refinement。一个有吸引力的 RSI pipeline 因而是：先利用 demonstrations/self-distillation 建立稳定 skill manifold，再只在 reward 能提供额外信息的位置执行小规模 RL residual update。ACLArena 的 MLE 已经提供了这一方向的初步工程实例。citeturn20search2turn25view0

第四个方向是双时间尺度 continual RL。SAFE 的 slow/fast learner、ACLArena 的 shared backbone/per-stage residual、CKA-RL 的 historical knowledge vector pool 都暗示可以把“长期稳定 representation”与“短期 reward-driven adaptation”拆开：fast subsystem 根据近期稀疏奖励快速变化，slow subsystem 仅在多次一致证据积累后 consolidation。对 reward 特别 sparse 或 delayed 的 RSI，这比每个 episode 都直接改 shared backbone 更合理。citeturn14search2turn15view0turn25view1

第五个方向是把 TD 的思想从 value learning 推广到“持续模型更新的证据聚合”。TD-VCL 的关键不是它本身是 RL 算法——作者明确说明它不是——而是它展示了一个有趣的数学事实：持续学习时不必只根据最近一个 posterior/checkpoint 约束下一步，可以像 n-step/TD(λ) 一样让多个历史估计共同形成 update target，从而减少单次错误信号的长期放大。对 sparse/infrequent reward，研究“checkpoint-level TD targets”或“posterior-level eligibility traces”是一个很自然但仍相对空白的方向。citeturn14search0turn19search0

第六个方向是专门构造 RSI Continual Post-Training benchmark，而不是继续只用静态 CL 分类任务。一个更有判别力的 benchmark 应同时包含：稀疏且延迟的 reward、部分错误 reward、真正改变的 facts、永远不应改变的 stable facts、周期性 regime shift、多技能 agent stages，以及 reward-free demonstrations；核心指标应至少同时报告 cumulative return/new-task score、backward forgetting、forward transfer、stable-knowledge retention、OOD transfer、reward/sample efficiency、parameter/update sparsity 和 GPU/VRAM cost。这套设计是综合 TempWiki、ACLArena、RFT-CPT、CKA-RL 与 Weight Space Consolidation 的实验缺口提出的。citeturn24view0turn17view0turn17view1turn25view1turn21search2

第七个方向是研究“什么时候根本不该学习”。在真实部署系统中，context/RAG、prompt memory、test-time adaptation 与 weight update 不应被视为竞争关系，而应形成一个 update hierarchy：短暂或低置信信号留在 context；重复但局部的信号进入 external/sparse memory；高置信、跨 episode 稳定的模式才 consolidation 到 shared weights；只有可验证 reward 足够可靠时才进行更激进的 RL update。Berkeley 的统一实验已经表明不存在一个 update mechanism 在所有 temporal/domain regimes 下都最好，因此“选择学习机制”本身很可能应该成为 RSI 的上层决策问题。citeturn22search0turn24view0

综合优先级判断：若目标是做一条兼具新颖性和当前研究势能的 RSI 研究线，最有吸引力的切入点是 reward-aware continual post-training with localized updates：建立一个能够判断 reinforcement signal 是否可信、是否代表持久变化的 gating module；根据该解释将 credit 路由到 sparse memory/LoRA expert；使用 SDFT 或历史 policy 做 dense auxiliary supervision；最后通过 replay/weight averaging/TD-style historical constraints 进行周期性 consolidation。这个组合恰好把目前彼此分散的 SDFT、RFT、Sparse Memory、ACLArena、TD-VCL、plasticity maintenance 六条前沿线汇合起来，但目前尚没有上述论文给出一个完整统一实现，因此这里应视为研究机会判断而非已被证明的最佳方法。citeturn20search2turn17view1turn22search5turn25view0turn19search0turn20search0
