 前人持续 RL 工作（RFT-CPT、ACLArena）证明 GRPO 具备强抗遗忘性，但均依赖 外部不随参数漂移的确定性规则（Stationary External Oracle） ；而现有自奖励/同底座共演化工作（Self-Rewarding LMs、Shafayat et al. 2025、CURE）仅在 单任务静态分布 下讨论。
 本文聚焦 跨阶段异质持续任务流（Continual Heterogeneous Stream） 这一正交盲区，构建具备确定性事后真值的受控科学实验台（Controlled Scientific Testbed），首次对共享参数下的裁判退化做 2×2 精确归因（参数污染 Subspace Pollution vs. 格式迎合 Sycophantic Hacking） 。我们提出轻量化三组件方案—— ① Dual-Adapter 物理隔离（作为 Fisher-Mask 连续谱的极限端点，继承 PPG 谱系）+ ② Replay-Grounded Contrastive Warm-up（含规则扰动与自一致性 Hard Negatives）+ ③ L2 Canonicalization 早停 ——在完全零训练期 Oracle 接触下恢复 GRPO 的抗遗忘与前向学习红利。

 ① 
 PPG (Cobbe et al. 2020) & 独立 RM 谱系 主动声明 Dual-Adapter 在功能上继承深度 RL 的 Phasic Policy Gradient（解耦共享 trunk 的策略与价值干扰），将其定位为"Fisher-Mask 连续谱的 100% 极限点与参数高效实现"，而非凭空发明隔离。
 ② 
 RFT-CPT (2507.05386) & Berkeley (2607.07847) 确立 GRPO 在有外部静态 Oracle 时优于 SFT，但极度依赖奖励排序质量。我们将"失去完美 Oracle 后 GRPO 抗遗忘红利大幅退化"明确列为待检验假设 H1 。
 ③ 
 WARM (Ramé et al. 2024) & ACLArena (2609.23989) 引用 WARM 的权重平均 RM 思想，指出跨异质阶段直接做 LoRA EMA 存在双线性交叉项误差与残差冲突，从而论证用 Replay-based Warm-up 替代 EMA 的必要性。
 ④ 
 Shafayat et al. (2025) / Shao et al. (2025) / Panickssery (2024) 正面引用近期自训练坍缩、Qwen 伪奖励（Spurious Rewards）与自偏好偏见（Self-Preference Bias）文献，将本文核心增量精准锁定在 "跨阶段异质任务流中的 2×2 漂移归因与无 Oracle 恢复" 。

 Problem Formulation · 消除动机矛盾
 受控科学实验台 & 组内排序失真
 F1 
 为什么在有确定性验证器的 4 个任务上不用训练期 Oracle？ 不再宣称"模拟没有验证器的真实部署"，而是定位于 受控科学实验台（Controlled Scientific Testbed） ：正如研究噪声标签学习需在有真值的 CIFAR 上人工注入机制一样，我们必须利用具备 100% 确定性程序真值的异质任务作为 事后显微镜（Post-hoc Microscope） ，才能无争议地计算 Proxy-Gold 排序偏差。
 F2 
 为什么主指标是组内排序精度 Acc_rank 而非 ECE？ GRPO 依赖组内相对优势 Â_i = (r_i − μ_r)/σ_r 。若 Judge 整体偏高 +0.3，ECE 极差但对 GRPO 毫无影响；反之若组内发生 排序倒置（Ranking Inversion） ，策略梯度直接反向。因此全文以 Acc_rank （伴随报告有效对覆盖率 Valid-Pair Coverage 与组内 Spearman's ρ ）为主指标， Reward Spread (σ_r) 与 ECE 为辅。
 F3 
 诚实命名架构实质 由于 Judge 在阶段内冻结且由少量未标注 Demo 对比预热，本文方法实质是 Demo-Grounded Lightweight GenRM + Continual GRPO + Self-Diagnostic Early Stopping ，避免过度绑定"Judge 随 Actor 自举变强"的狭义自奖励标签。

 Conceptual Error Decomposition · 概念性分解（非定理包装）
 组内排序失真的三源概念分解：三大核心组件的一一映射
 采纳审稿建议，我们将原公式明确界定为指导实验设计的 概念性分解框架（Conceptual Decomposition Framework） 而非形式化数学定理，将第 t 阶段第 k 步 Judge 在组内的排序失真（Ranking Inversion Risk）归结为三类机制来源，并精简方法为三个核心组件（砍掉默认 EMA，消除"Kitchen Sink"堆砌感）：
 RankingError(θ_J^(t,k), π_A^(t,k))  ≈ 
 ① Cold-Start Decision Boundary Misalignment  + 
 ② Cross-Role Parameter Pollution (m < 1)  + 
 ③ On-Policy Format Sycophancy (Δr_canon) 
 ① 
 应对来源 ①（冷启动判别失明 + 跨阶段遗忘）↔ 组件 1：Replay-Grounded Contrastive Warm-up 每阶段入口用 100–200 条未打分 Demo 构造正例，结合 "规则扰动 + Base 平滑"与"自一致性少数派"双路线 Hard Negatives 构造负例，并 直接重放历史阶段对比对（每阶段仅百余条，耗时 <3 分钟） 。直接替代有损且引入超参 α 的 LoRA EMA！
 ② 
 应对来源 ②（跨角色参数干扰）↔ 组件 2：Fisher-Masked 连续谱与 Dual-Adapter (m=1.0) 在共享参数（ m < 1 ）下，Actor 梯度沿着 Judge 高 Fisher 敏感坐标写入，导致排序退化率随共享可塑容量和步数增长；Dual-Adapter 对应坐标掩码比例 m = 1.0 的完全解耦极限端点。
 ③ 
 应对来源 ③（同阶段格式迎合）↔ 组件 3：L2 Canonicalization 早停协议 即使物理隔离了参数（ m = 1.0 ），Actor 仍会通过迎合固定 Judge 的表面文风偏见来刷分。通过监控组内 Reward Spread (σ_r) 、自偏好超越率 ρ_over 与 去格式改写敏感度 Δr_canon ，精准识别并截断格式投机。

 Component 1 · GenRM Interface & Dual-Adapter Spectrum
 确定性 GenRM 打分接口 + Dual-Adapter 物理隔离架构
 GenRM 连续概率输出（消除采样噪声）
 R Greedy Rubric CoT + Logit 差值 Judge 采用 temperature = 0 贪心解码生成简短判据（上限 192 tokens ），末尾输出 Verdict: [[Yes]] / [[No]] ，取最后一层 logit 计算连续奖励： r(x,y) = σ(z_Yes − z_No) ∈ (0,1) 。彻底消除采样随机性对 GRPO 组内方差的干扰。
 R Response-Level 统一粒度 + No-CoT 消融 全 4 阶段统一为 response-level 打分（撤回"Stage 1 step-level process RM"的不一致承诺）；在 Ablation 中对比 Direct-Logit (0 CoT) 以量化推理开销（约 1.6× rollout 耗时）与排序精度的权衡。
 Frozen Base W₀ + θ_A (r=64) ⊕ θ_J (r=32)
 A Actor Adapter θ_A (r_A = 64) 前向采样激活 W₀ + ΔW(θ_A) ，反向仅接收 GRPO 梯度；阶段内完全可塑。
 J Judge Adapter θ_J (r_J = 32) 打分时卸载 θ_A，激活 W₀ + ΔW(θ_J) 。阶段内完全冻结，仅在阶段切换处通过 Replay Warm-up 更新（EMA / Growing-Rank SVD Merge / Per-stage Expert + MLP Router 全部降为 Ablation）。

 Component 2 · Replay-Grounded Contrastive Warm-up
 攻克"风格 Shortcut"：双路线 Hard Negatives + 历史对比对重放
 若正例仅用人类 Demo、负例仅用旧 Actor 生疏输出，Judge 极易退化为"文风判别器（Style Detector）"，导致 Actor 模仿格式后迅速满分饱和。我们设计 双路线 Hard Negatives + Base 平滑脱敏 + 历史对比对 Replay （每阶段 Warm-up 80 步，耗时 ~15 分钟）：
 1 
 路线 A：分领域规则扰动 + Frozen Base 平滑（Rule-Perturbed + Paraphrase Smoothing） 对 D_t^demo （150 条）施加领域特定逻辑破坏（见下阶段表），随后 强制经过冻结 Base 模型 W₀ 做一次保持格式的自然语言重写平滑 ，彻底抹除机械篡改留下的突兀编辑痕迹（防止"检测编辑痕迹"新 Shortcut）。
 2 
 路线 B：自一致性少数派负例（Self-Consistency Minority Rollouts，零 Oracle） 用进入阶段 t 前的模型采样 K=8 条 rollout，选取偏离多数派共识的自然错误轨迹作为天然同格式负例（各阶段一致性定义见下表）。
 3 
 跨阶段防遗忘：直接 Replay 历史对比池（替代 LoRA EMA） 阶段 t 预热时，将阶段 1…t−1 存下的对比对（每阶段仅 150 对，总计 <500 对）按 1:1 混合重放训练 Bradley-Terry 二元交叉熵损失，零超参、无损保留旧阶段判别边界。
 4 
 事后盲测验证： Correctness-AUROC vs. Style-AUROC （仅在 Pilot / L3 报告，绝不进训练 Loop） 
• Correctness-AUROC ：同为模型自然生成格式，由事后 Gold Oracle 标注 (Correct, Incorrect) 对，检验实质判别力（目标 > 0.80）；
• Style-AUROC ：同为 Gold Oracle 判定正确的回答，配对 (Human Demo 格式, 模型自生成正确格式) ，检验风格偏见（目标 ≈ 0.50）。

 Component 3 · Double-Blind Protocol & L2 Canonicalization Probe
 三层盲测隔离 + 修复 L2 空操作 Bug：基于格式脱敏的早停机制
 修复原方案 Bug： 在 Dual-Adapter 下 θ_J 阶段内冻结，静态锚点上的 Kendall's τ 恒等于 1（空操作）；且单看自偏好率 ρ_over = Pr(r(y_actor) > r(y_demo⁺)) 无法区分"Actor 真正变强"与"Actor 学会骗裁判"。重构后的三层协议如下：
 L1 
 Training Loop（在线训练层） 100% 由冻结的 θ_J 输出 r̂_self 驱动 GRPO，零外部 Oracle 参与。
 L2 
 Unsupervised Self-Diagnostic Early Stopping（每 15 步检测一次，阈值在 Pilot Stage 1 预注册冻结） 联合监控三个纯内部无监督信号：
① Reward Spread σ_r(k) ：监控组内奖励标准差是否坍缩（优势信噪比监控）；
② Self-Preference Over-Demo Rate ρ_over(k) ：在 100 条阶段锚点题上，当前 Actor 输出得分超越原始人类 Demo 的比例（参考 Panickssery et al. 2024）；
③ Canonicalization Drop Δr_canon(k) （核心判据） ：对锚点题上的 Actor 输出 y_actor 做一次 去格式等价改写 （剥离 Markdown 装饰前缀、用冻结 Base W₀ 做句式重写或调换并列步骤）得到 ỹ_actor ，计算同一 Judge 打分跌落值 Δr_canon = E[r(y_actor) − r(ỹ_actor)] 。
👉 判定逻辑： 若 ρ_over > 0.80 但 Δr_canon 很小 → 真能力提升，继续训练 ；若 ρ_over > 0.80 且 Δr_canon > τ_canon （剥掉格式马甲后分数暴跌）或 σ_r < τ_spread → 实锤 Sycophantic Hacking，立即触发早停！ 
 L3 
 Post-hoc Blind Audit（事后盲测层——Gold Oracle） 所有训练与早停完成后，调用确定性程序验证器一次性算出真实准确率 r_gold 、组内排序精度 Acc_rank （及 Valid-Pair Coverage ）、 Spearman's ρ 与 Correctness/Style-AUROC 。

 立即执行清单（按死穴优先序排列）
 【Step 0 · 最高优先】跑 Stage 1 → Stage 2 的双重效应量预检门（Effect-Size Gate） 在动手跑任何对比组之前，先验证 Shared-LoRA (r=64) 是否满足 FM < −4.0% 且 P_ext 上 ΔAcc_rank < −8.0% 。若效应不够大，立即在同 LoRA 参数化下调大 Rank (r=128) / LR / 阶段步数，并在此步预注册冻结 L2 早停阈值与 TOST 边界（ δ = ±2.0% ）。
 【工程打通】编写 verl 的 rollout → GenRM LoRA 回调接口与双路线 Hard Negatives 构造脚本 利用 vLLM 原生 LoRARequest 实现同一进程内 θ_A 生成与 θ_J （Greedy CoT ≤ 192 tokens + Yes/No Logits）打分；完成四阶段规则扰动算子 + W₀ 平滑重写脚本。
 【Pilot 实验】运行 Group A/B/C/D（含 Fisher-Masked 连续谱因果干预与双 AUROC 检验） 验证 Style-AUROC ≈ 0.50 （排除风格 Shortcut），画出 m ∈ {0%, 25%, 50%, 75%, 90%, 100%} 的因果干预曲线，并用 TOST 检验确认 Group C 在 P_ext 上的零污染。
 【主实验】跑满 Qwen2.5-7B-Instruct (8 行 × 3 Seeds) + Llama-3.1-8B-Instruct (核心 3 行 × 3 Seeds) 重点盯防 SDFT-Only （证明 RL 必要性）与 Judge Co-Training （对比准确度与每步双 Backward 算力成本），所有阶段严格执行零训练期 Oracle 接触。
 【Ablation 消融】对比 Replay Warm-up（默认）vs. Growing-Rank SVD Merge vs. Per-stage Judge Expert 汇报截断 SVD 的保留谱能量比例，实证为什么简单的历史对比对 Replay 优于有损 LoRA 权重平均。
