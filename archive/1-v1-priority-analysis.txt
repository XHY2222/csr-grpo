 Paper 核心主张
 Actor-Judge 双重漂移：持续自奖励 RL 的诊断与修复
 前人（RFT-CPT、ACLArena）发现用 GRPO 做持续训练天然抗遗忘，但那是因为他们依赖 永远不会随模型参数漂移的外部规则裁判（Stationary External Oracle） ；而现有的自奖励工作（Self-Rewarding LMs）虽然摆脱了外部规则，却只在 单任务静态分布 下验证。
 本文首次揭示这一 正交盲区（Orthogonal Blindspot） ：当在持续任务流中用模型自给自足提供奖励时，Actor 的策略梯度会率先污染共享参数中的裁判子空间（Judge Subspace），导致 Capability Drift（生成退化） 与 Reward Calibration Drift（裁判失准） 双重崩塌，使 GRPO 的抗遗忘红利破灭。通过 Dual-Adapter 物理隔离 + SDFT 冷启动，我们在完全不依赖训练期外部 Oracle 的前提下，将持续自奖励 RL 的表现拉回逼近完美外部 Oracle 的上限。
 弥合"持续 RL"与"自奖励"正交盲区 
 揭示失去完美 Oracle 时 GRPO 抗遗忘红利缩水 75% 
 三项误差分解理论框架 
 Dual-Probe 解耦污染与迎合 
 Dual-Adapter 物理隔离 + SDFT 冷启动

 Problem Formulation · 防审稿人质疑
 精准界定现状：为什么"外部静态规则"不可持续，而"直接换 Self-Judge"会翻车？
 为避免审稿人批评"稻草人谬误"，本文在 Introduction 中精准界定当前 2025–2026 文献分裂出的 两条互不交叉的平行线（The Orthogonal Blindspot） ，并剖析两套路线的各自死因：
 路线 A：现有 Continual RL（100% 依赖外部免维护静态规则）
 代表：RFT-CPT (7个VQA精确匹配)、Berkeley 2607.07847 (GT标签)、ACLArena (环境确定性反馈)。
 可扩展性瓶颈（Scalability Bottleneck）： 真实持续部署中（如新网页结构、复杂工具组合），不可能实时为每个新任务编写完备的 Python 单元测试或 SymPy 校验器。
 极端稀疏性导致可塑性饥饿（Plasticity Starvation）： 静态规则仅在末尾给 0/1 结果奖励。进入全新阶段初始成功率接近 0% 时，GRPO 采出的 rollout 全为 0 分，优势函数归零，模型完全学不动。
 路线 B：直接将外部规则替换为共参数 Self-Judge（三大灾难）
 代表：将 Self-Rewarding LMs / RLAIF 直接放入多阶段连续任务流。
 ① 裁判子空间污染（Judge Subspace Pollution）： Stage 2 的 Actor RL 梯度改写共享权重，导致模型先忘了"怎么评判 Stage 1 的对错"（ECE 暴涨），反过来用错误信号加速摧毁旧技能。
 ② 迎合式协同坍缩（Sycophantic Co-adaptation）： 共参数 Judge 对自身生成的特定格式产生高置信度偏见，导致 r̂_self 虚高而真实 r_gold 倒 U 型坍缩。
 ③ 新阶段冷启动失明（Cold-start Blindness）： 若为防漂移而死锁旧 Judge，切入新领域（如 Logic→Code）时裁判打分形同掷硬币（AUROC ≈ 0.5）。

 Theoretical Grounding · 三项误差分解
 奖励失真分解不等式：为什么 Dual-Adapter + SDFT Warm-up + L2 早停缺一不可？
 为消除方法设计的"工程拼凑感"，我们在 Section 2 开篇将第 t 阶段第 k 步的自奖励失真（Total Reward Drift）严格分解为三项独立误差上界，使本文的三个核心组件分别精确消除其中一项：
 E_{y~π_A}[ |R(θ_J^(t,k)) − R*_t| ]  ≤ 
 ① ‖R(θ_J^(t,0)) − R*_t‖_{D_t} (Cold-Start OOD Gap)  + 
 ② ‖∑ (∂R/∂θ_shared)·Δθ_A^(t,j)‖ (Parameter Pollution)  + 
 ③ √(½ d_KL(π_A^(t,k) ‖ π_A^(t,0)))·L̂_R (Sycophantic Shift) 
 ① 
 消除第 ① 项（Cold-Start OOD Gap）↔ SDFT-bridged Warm-up： 为什么不用 Gold Reward 标签也能校准 Judge？从 Bradley-Terry 偏好模型看，校准 Judge 只需知道新任务分布上的偏序对 (y⁺, y⁻) 。SDFT 未标注示范 y⁺ ~ D_t^demo 天然位于高奖励流形，而旧策略零样本采样 y⁻ ~ π_A^(t-1) 位于次优流形——用 (y⁺, y⁻) 做对比预热，在信息论上等价于在 R*_t 支撑集边界上完成了一次 一阶决策边界对齐（First-order Decision Boundary Alignment） 。
 ② 
 消除第 ② 项（Cross-Role Parameter Pollution）↔ Dual-Adapter 物理隔离： 由于 θ_A ∩ θ_J = ∅ 且 Base W₀ 冻结，交叉雅可比项 ∂R / ∂θ_shared ≡ 0 ，从微积分链式法则（Chain Rule）上直接令第 ② 项恒等于零。
 ③ 
 约束第 ③ 项（On-Policy Sycophantic Shift）↔ EMA 跨阶段锚定 + L2 无监督早停： 即使没有梯度污染，Actor 针对固定 Judge 过度优化仍会拉大 d_KL 产生格式迎合。其中经验敏感度常数 L̂_R 直接取自 Pilot Group D 实测的 Judge 梯度范数 （消除无界 Lipschitz 假设），并在 Section 4 与 Group C 实测的 ΔECE_sycophancy 定量比对，形成完整的"理论预测—实验验证"闭环。
 📎 
 Appendix 严谨性说明（交叉项消除）： 通过三角不等式依次插入桥接项 R(θ_J^(t,0)) 与初始分布期望，并利用"先完成阶段入口 Warm-up 固定 θ_J^(t,0) 、再启动在线 RL 步 k "的时序解耦设计，原本的二阶交叉项 O(‖Δθ_J‖·d_KL) 在单阶段内严格归零，跨阶段余项可归入有界常数。

 Algorithm · Frozen Base + Dual-Adapter Routing
 物理隔离架构：Actor Adapter θ_A ⊕ Judge Adapter θ_J
 冻结预训练 Base Weights W₀ ，挂载两套正交职责的 LoRA 模块。
 无论 Actor 的 RL 梯度将生成分布扭曲成何种形态，Judge 看到的底层表征永远是干净的 W₀ + ΔW(θ_J) ，
 从物理上斩断 Actor 梯度对 Judge 表征的直接污染。两套 LoRA 合计 <400MB，比存两个 7B 模型省约 14GB 显存。
 Actor Adapter θ_A
 A Rank r_A = 64，挂在全部 Linear 层 前向 Rollout 时只激活 W₀ + ΔW(θ_A) 
 A 反向只接收 GRPO 策略梯度 完全可塑（High Plasticity），自由探索新任务
 A Base Weights W₀ 全程冻结 Actor 梯度永远写不进 base，Judge 子空间物理隔离
 Judge Adapter θ_J
 J Rank r_J = 32，独立参数空间 打分时卸载 θ_A，只激活 W₀ + ΔW(θ_J) 
 J 仅在两个时刻更新 ① 每阶段 Cold-start Warm-up；② 跨阶段 EMA 慢速合并
 J EMA 合并公式 θ_J^(t) ← α·θ_J^(t-1) + (1-α)·θ_J,warm^(t) 锚定历史校准分布
 ⚠️ 
 工程确认（最高优先级）： 推理时 Actor/Judge LoRA 切换在 vLLM 是 request-level，verl 框架下需确认是否支持 per-forward multi-LoRA 切换。若不支持，需自行实现 adapter switching hook，留出工程时间，先于第一次实验确认。

 Algorithm · SDFT-bridged Judge Warm-up
 Cold-start 机制：每阶段入口处的 Judge 冷启动（~15 分钟）
 EMA 只能防止旧 Judge 变坏（防 Backward Drift），但进新阶段时旧 Judge 根本不懂新任务格式（无 Forward Plasticity）。
 Cold-start 机制不依赖新任务的 Gold Reward 标签——只需极少量未打分示范 D_t^demo （N = 100–200 条，SDFT 标准设定）。
 1 
 Constructive Contrast（自构造正负对比） 用进入阶段 t 前的旧 Actor 对这 100 条题目采样 K=4 条 rollout，天然作为 sub-optimal / negative 样本； D_t^demo 中的 demonstration 作为 positive 样本，配对组成对比数据。
 2 
 Rubric-grounded Judge Warm-up（约 50–100 步） 只更新 Judge Adapter θ_J，让 Judge 学会区分"旧策略对新任务的生疏输出"与"新阶段标准格式/示范"；同时用 SDFT 的 reverse-KL 约束防止破坏前 t-1 阶段的判别分布。
 3 
 Stage 3 (Code→Math) 边界条件 旧 Actor 在 Math 上可能产生"看起来有道理但答案错"的 ambiguous negative，会污染 warm-up 信号。仅在此阶段的 warm-up 中，允许用 Gold Oracle 过滤 rollout（只保留 Oracle 明确判为错误的样本作为 negative）。这是唯一允许在训练期间看 Oracle 的位置，时机是 warm-up 阶段而非主训练，审稿人可接受。
 ✅ 
 实验对照价值： 可在图上干净分离三条曲线——① 纯 EMA Judge（死于 Cold-start 瞎打分）→ ② 只加 Warm-up 不做参数隔离（初期准，随后死于 Actor RL 梯度污染）→ ③ 完整方案（既能冷启动，又不漂移）。

 Evaluation · Double-Blind Protocol
 三层信号完全隔离：杜绝 Gold Oracle 间接泄漏
 只要在训练期间用 Oracle 结果做早停或选超参，审稿人就会判定为 Test-set Leakage / Oracle-assisted tuning。三层隔离协议写入论文 Experimental Setup 小节。
 L1 
 Training Loop（在线训练层） 100% 由 Judge Adapter θ_J 打出的 r̂_self 驱动 GRPO。无任何外部 Oracle 参与。
 L2 
 Hyperparameter & Early-Stopping（超参/早停层——无 Oracle） 只看两个无监督内部监控指标：① Self-Reward Entropy/Saturation ：当 θ_J 对 rollout group 的奖励方差坍缩（出现 reward hacking 饱和征兆）；② Anchor Consistency（Kendall's τ） ：在每阶段开头存下的 100 条 Cold-start 样本上，当前 θ_J 打分与初始 θ_J^(t,0) 打分的 Kendall's τ 秩相关跌破阈值。 注：Kendall's τ 曲线本身可作为 Section 4 Analysis 的独立子图，展示 Judge 校准稳定性随阶段推进的变化。 
 L3 
 Post-hoc Blind Audit（事后盲测层——Gold Oracle） 仅当 L2 协议跑完所有阶段、固定唯一最终 Checkpoint 序列后，才调用外部规则验证器（SymPy / Code Executor / Constraint Checker）一次性跑出真实准确率 r_gold 和 ECE。训练期间的任何决策均未使用此结果。

 Benchmark Design
 4-Stage Verifiable Heterogeneous Stream
 每个阶段同时满足：① 100% 具备确定性程序 Oracle（客观真值，无需 LLM 评判）；② 四阶段技能真正异质（产生严重遗忘和跨阶段冲突）；③ 能清晰解释"为什么训练时用 Self-Judge 而不用 Oracle"。
 统一论证框架： "我们假设 training-time oracle 不可用（昂贵、专有或反馈延迟），这是真实 post-training 部署中的常态；oracle 仅用于事后科学评估。"

 Pilot 因果诊断实验（Section 3 · Motivation）
 🔬 
 2-Stage Controlled Pollution Pilot
 两阶段受控污染诊断：一锤定音证明 Actor 梯度污染 Judge 子空间
 在 8 × H800 上只跑 Stage 1 (Logic) → Stage 2 (Code)，约 4.5 小时。为严格区分 Subspace Pollution（梯度冲坏裁判参数） 与 Sycophantic Co-adaptation（无梯度干扰下的纯输出格式迎合） ，设计 内外双探针（Dual-Probe Diagnostic） ：
• P_ext （外来静态探针）：由 Stage 1 结束时的 Actor 冻结快照 W₀ + ΔW(θ_A^(1,end)) 生成的 500 条固定 Stage 1 回答（与 Judge 在 Stage 1 校准时的输入分布完全对齐且静止，避免 W₀ 裸模型带来的额外分布偏移；若 Stage 2 期间 ECE 上升则 100% 归因于参数污染）；
• P_on-policy （同源动态探针）：由当前训练中的 Actor 实时采样的回答（同时反映参数污染 + 格式迎合）。
